# Data Extraction Engineer Hiring Challenge

## Setup Instructions
1. Install requirements: `pip install -r requirements.txt`
2. Run Objective 1 script: `python disney_cruise.py`
3. Run Objective 2 script: `python ingredients_network.py`

## Architecture Strategy
This framework uses a robust hybrid execution pipeline: **Selenium** drives structural page state changes, actions, and scrolling parameters. **BeautifulSoup** strips raw text layers safely, and **Pandas** structures data metrics cleanly into intermediate RAW caches and pristine final production CSV outputs.
